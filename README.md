# Comet Innovations website

Static pages in `public/`, served by a small Express server (`server.js`, `app.js`) that also handles the contact form. Hosted on Railway.

## Run locally

```sh
npm install
npm start          # http://localhost:3000
npm test           # server and contact form tests
```

## Deploy on Railway

1. Create a service from this repository. Railway detects Node and runs `npm start`; `railway.json` sets the health check to `/healthz`.
2. Add these variables so the contact form can send email through [Resend](https://resend.com):

   | Variable | Example | Purpose |
   | --- | --- | --- |
   | `RESEND_API_KEY` | `re_...` | Resend API key |
   | `CONTACT_TO_EMAIL` | `hello@example.com` | Where enquiries are delivered (comma-separate several) |
   | `CONTACT_FROM_EMAIL` | `Comet Website <website@example.com>` | Sender; its domain must be verified in Resend |

   Without them the site works but form submissions return an error and log `Contact form is not configured`.
3. Attach your custom domain in Railway's networking settings.

## Imagery

The hero scenes, card textures and glyphs in `public/images/` are generated by `tools/generate-art.py`. Any of them can be replaced with photography: keep the file name, or update the `src`, and keep a similar aspect ratio.

## Fonts

Self-hosted in `public/fonts/` under the SIL Open Font License: Inter (body and labels) and Cormorant Garamond (headlines).
